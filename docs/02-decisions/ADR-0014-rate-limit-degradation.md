# ADR-0014: 限流降级策略（按接口分类，不是全局一刀切）

- **状态**：已接受
- **日期**：2026-09-29
- **决策者**：Wingtisky（决策） / Claude（建议）

## 背景

亮点 5 的限流依赖 Redis 记录计数。**Redis 挂掉时限流器就没有判断依据了**——这是任何基于外部存储的限流都无法回避的问题。

此时有三种处理方式，而不是两种：

| 选项 | 做法 | 效果 |
|---|---|---|
| fail-open | 放行 | 限流暂时失效，可能被刷 |
| fail-closed | 拦住所有请求 | **整个站点不可用** |
| 降级到本地内存 | 退回单机计数 | 精度下降，但仍有保护 |

选哪个，不能凭"哪个听起来更安全"。

## 候选方案

### 方案 A：全局 fail-closed
- 优点：限流永远不失效，安全上最保守
- 缺点：**Redis 是单点，抖一下全站就不可用**

### 方案 B：全局 fail-open
- 优点：可用性最好
- 缺点：**登录接口的限流其唯一目的就是防撞库**——放行等于在最需要它的时候把门打开

### 方案 C：按接口分类（**选中**）
- 优点：不同类型的接口用不同的策略
- 缺点：配置更复杂，需要想清楚每个接口属于哪一类

## 决定

采用**方案 C**。具体分类：

| 接口 | 降级策略 | 理由 |
|---|---|---|
| 普通业务接口 | **fail-open** | 限流失效的代价 < 全站不可用的代价 |
| 秒杀 / 支付（M7/M8） | **fail-open** | 正确性由 Lua 扣减与幂等兜底，限流只负责减压 |
| 登录 / 注册 | **降级到本地内存** | 放行 = 防撞库失效；全拦 = 谁都登不进来 |

## 理由

判据是两个问题，不是"哪个更安全"。

**问题一：限流在这里是不是"正确性防线"？——不是。**

这是整个决策的关键区分。限流是**防滥用**，不是保证正确性：

| 要防的事 | 真正靠什么防 | 靠限流吗 |
|---|---|---|
| 优惠券超卖 | Redis Lua 原子扣减（亮点 6） | ❌ |
| 重复下单 / 重复扣款 | 幂等（`eventId` + 唯一索引） | ❌ |
| 订单状态错乱 | 状态机 + 本地消息表（ADR-0011） | ❌ |

**正因为正确性另有保障，限流失效才不会让钱算错。** 这是"支付场景也能 fail-open"的底气——不是因为支付不重要，而是因为**限流本来就不是它的安全绳**。

**问题二：两种失败的代价，哪个更大？**

本机 Redis 是单点，没有哨兵没有集群。fail-closed 意味着 **Redis 抖一下，全站 502**。用"可能被刷"换"全站不可用"不划算。

**那为什么登录接口不用 fail-open？** 因为那个限流的**目的本身**就是安全。普通接口的限流是"保护后端资源"，失效了只是资源压力大一点；登录接口的限流是"防止有人暴力猜密码"，失效了就是**攻击者可以无限尝试**。目的不同，降级方式就该不同。

## 后果

- **正面**：Redis 故障时全站仍可用；最需要保护的接口仍有保护（降级而非失效）
- **负面**：
  - 配置更复杂——每个接口都要判断它属于哪一类，判断错了就是一个安全缺口
  - **本地内存兜底是固定窗口，不是滑动窗口**：它在窗口边界会放过接近两倍的量。作为临时兜底可接受，但**不能把它当成 Redis 版的等价替代**
  - **本地兜底在 M9 拆多实例后会变成"每个实例各限一份"**（N 个实例放行 N 倍）。届时要么给 Redis 上哨兵，要么把登录接口改成 fail-closed。现在不做（YAGNI），但必须记住这个时点

## 被否决方案为何不选

- **方案 A（全局 fail-closed）**：把"Redis 单点故障"直接放大成"全站故障"。本项目限流的目的里，**只有登录接口那一处**属于安全边界，为它把全站陪进去不划算
- **方案 B（全局 fail-open）**：等于承认"限流在最需要的时候可以失效"。而登录接口恰恰是最需要的那个

## 实测验证

本策略不是纸面设计，**按接口分类的降级实测通过**（停掉 Redis 后）：

| 接口 | 配置 | 实测结果 |
|---|---|---|
| 登录 | `fallback=local` | **仍限在 10 次**，第 11 次 429 ✅ |
| 普通接口 | `fallback=open` | **正常放行 200**，未被误伤 ✅ |

日志记录 15 条 `ERROR 限流降级：Redis 不可用, path=/api/auth/login, 策略=LOCAL`——
**任何降级都会留下信号**，否则"限流正在失效"这件事没有任何人会发现。
