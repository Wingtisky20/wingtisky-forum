## 关键事实（接手必读）

### 架构已大改（2026-09-13）

业务域从「纯论坛」扩展为「技术社区 + 付费内容（含秒杀）」，拆分为 3 个服务。

- **M0–M8 是「逻辑态」**：一个进程，模块边界已按三域划好，由 ArchUnit 强制
- **M9 才「物理态」**：拆三个进程 + Nacos + Gateway，并做拆分对照实验
- **拆分理由是「故障域隔离」**，不是性能/伸缩/团队分工

**旧 9 模块骨架（提交 `e2619a2`）已被架构变更取代，且已于 Task 1 删除。** 现行结构见下方「模块结构」。

Spring Boot **3.5.16** · Redisson **3.52.0** · Caffeine **3.2.4** · ArchUnit **1.5.0**
**不上 4.x 线**——Redisson 4.x 可能要求 Redis 6+，而本机 Redis 为 5.0.14.1。
